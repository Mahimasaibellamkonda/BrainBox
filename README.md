# BrainBox – Puzzle & Brain Games Hub

BrainBox is a web-based collection of mini brain games designed to test and improve different skills such as logic, reaction speed, problem-solving, and vocabulary.

##  Games Included

###  Number Guess

Guess the secret number between 1 and 100. The game provides hints to help you find the correct number.

###  Reaction Test

Test your reaction speed by clicking the screen as soon as the signal appears.

###  Word Scramble

Unscramble the given letters and find the correct word.

###  Tic-Tac-Toe

Play the classic Tic-Tac-Toe game against the computer.

##  Technologies Used

* HTML5
* CSS3
* JavaScript

##  Features

* Multiple interactive mini-games
* Simple and user-friendly interface
* Responsive design for different screen sizes
* Interactive game logic using JavaScript
* Randomized challenges
* Score and attempt tracking
* No backend required

##  How to Run

1. Download or clone this project.
2. Open the `BrainBox` folder.
3. Open `index.html` in a web browser.
4. Select any game and start playing.

##  Project Objective

The main objective of BrainBox is to demonstrate the use of HTML, CSS, and basic JavaScript by developing an interactive website containing multiple browser-based games.
