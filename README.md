
#  BrainBox — Play. Think. Improve.

BrainBox is a browser-based mini-games website built with **HTML, CSS, and JavaScript**. It brings together four fun challenges to test your logic, reflexes, vocabulary, and strategy — all in one place.

🔗 **Live Demo:** https://mahimasaibellamkonda.github.io/BrainBox/

##  Features

###  Number Guess
- Guess a randomly generated number between 1 and 100.
- Get hints to find the secret number.
- Track your attempts.
- Start a new round whenever you want.

###  Reaction Test
- Test your reaction speed in milliseconds.
- Wait for the box to turn green before clicking.
- Get an early-click warning.
- Track your latest and best reaction times.

###  Word Scramble
- Unscramble mixed-up letters to find the hidden word.
- Explore words from different categories.
- Track your score and progress through rounds.
- Skip a word and try another challenge.

###  Tic-Tac-Toe
- Play as X against the computer as O.
- Challenge a computer opponent powered by the minimax algorithm.
- Win, lose, or draw and keep track of round scores.
- Restart a round and try a different strategy.

##  Getting Started

You can play BrainBox online using the live demo, or run it locally.

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Choose a game and start playing!

No backend or database setup is required.

##  Responsive Design

BrainBox is designed to work on desktop, tablet, and mobile screens.
